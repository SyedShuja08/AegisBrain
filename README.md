# AegisBrain 🛡️🧠

> **Live Application:** [https://aegis-brain-phi.vercel.app](https://aegis-brain-phi.vercel.app)  
> **Backend API:** [https://aegisbrain.onrender.com](https://aegisbrain.onrender.com)

AegisBrain is an enterprise policy-synchronization governance middleware layer that converts chat decisions into active rules and validates actions taken by AI agents in real time.

---

## ⚡ Key Features

* **Real-Time Policy Governance:** Intercepts AI agent actions and validates them against dynamic rule-sets before execution.
* **Live Gateway Dashboard:** Real-time visibility into incoming policy checks and agent execution status.
* **Manager Portal:** Portal for administrators to manage, sync, and audit operational rules.

---

## 🛠️ Tech Stack

* **Frontend:** Next.js, React, Tailwind CSS (Deployed on **Vercel**)
* **Backend:** Python, FastAPI, Uvicorn (Deployed on **Render**)
* **Database:** SQLite / Supabase
* **Deployment:** Vercel (Frontend) + Render (Backend) auto-deploys via GitHub
